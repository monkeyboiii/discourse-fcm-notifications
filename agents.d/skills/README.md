# skills

Repo-local skills for fcm-notifications: `<name>/SKILL.md` (+ optional `scripts/`) with frontmatter `name`
(== the directory) and `description` (ending in an `Args:` clause). Carry the repo in the name
because the harness links every skill into one flat namespace (`dbx skills sync`) and renders
the description with `dbx skills list` / `dbx skills show NAME`.
